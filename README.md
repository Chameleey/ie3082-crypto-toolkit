<hr>

<h2>📌 Overview</h2>
<p>
This project evaluates the performance and security of modern cryptographic algorithms 
including AES, RSA, ECC, and SHA-256. A custom Python-based toolkit was developed 
to perform encryption, decryption, hashing, and benchmarking across multiple file types.
</p>

<hr>

<h2>🛠️ Installation</h2>

<pre>
pip install -r requirements.txt
python install.py
</pre>

<hr>

<h2>🛠️ Implementation</h2>

<ul>
<li>🔐 AES-256-GCM encryption with authentication</li>
<li>🔑 RSA-3072 hybrid encryption</li>
<li>⚡ ECC (Ed25519 / Curve25519) for key exchange</li>
<li>🔍 SHA-256 hashing for integrity verification</li>
<li>📊 Benchmarking (execution time, throughput, memory)</li>
</ul>

<hr>

<h2>📊 Results</h2>

<ul>
<li>🚀 AES → Best for bulk encryption</li>
<li>🔐 RSA → Suitable for key exchange</li>
<li>⚡ ECC → Efficient for signatures</li>
<li>📊 SHA-256 → Fastest for integrity</li>
</ul>

<hr>

<h2>🧠 Security Considerations</h2>

<ul>
<li>Secure key generation (CSPRNG)</li>
<li>AES-GCM ensures confidentiality + integrity</li>
<li>RSA uses OAEP padding</li>
<li>No insecure modes (ECB avoided)</li>
</ul>
